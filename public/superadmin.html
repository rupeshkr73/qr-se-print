✅ Brevo — recommended (free, 300 email/din)

Hosting (Render) SMTP ports block karti hai, isliye Gmail/SMTP wahan kaam nahi karega. Brevo HTTPS se bhejta hai — wo hamesha chalta hai.

Setup (3 minute):
1. brevo.com par free account banao
2. Senders me apna email add karke verify karo
3. SMTP & API → API Keys se ek key banao
4. Dono neeche daal do

⚙️ SMTP (advanced — apna server ho tabhi)

Gmail SMTP Render par timeout deta hai (port block). Ye sirf tab bharo jab aapki hosting SMTP allow karti ho.

ℹ️ Ye kaise kaam karta hai

🆕 Nayi shop register ho → turant email
💰 Payment aaye → dobara email
🎯 Demo shop → koi email nahi (warna spam ho jata)
🏷️ White-label ki shop ka alert us partner ke email par jata hai, aapke paas nahi — kyunki wo unka business hai.
